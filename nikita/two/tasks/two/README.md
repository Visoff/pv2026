Задания второго блока(методы массивов) выполняются *без* явных циклов(while, for, do while)

На помощь приходят методы массивов:
- forEach
- map
- filter
- reduce
- every
- some
- find
- indexOf
- ...

Про них можно почитать [тут](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array)
