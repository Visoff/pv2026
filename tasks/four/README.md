Задача: написать проект на React

Минимальные требования:
- 2 счётчика "голосов" с возможностью голосовать
- кнопка для подведения результатов

Подзадачи:
1. Создать проект с помощью `npm create vite`(если написать название проекта ".", то он создаст проект в текущей папке), framework надо выбрать React с вариантом JavaScript
2. Почистить проект от счётчика, который идёт по умолчанию
3. Написать компонент для голосования(кнопка с увеличением счётчика при нажатии)
4. Написать компонент для подсчёта голосов(победившую партию можно вывести пользователю через alert)
5*. Сохранение голосов в localStorage
6*. Настройка названий партий до голосования
