# Задание

1. Дать мне свой гитлаб, что бы получить доступ к репо
2. git clone репозиторий с гитлаба на локальное устройство
3. Создать новую ветку и перейти в неё
4. Запустить проект
5. Поменять текст на свой
6. Пушить на гитлаб

# Запуск проекта

```bash
npm install
npm run dev
```

# Видимый результат

Мне от вас нужно получить:
1. Имя пользователя gitlab
2. Скрин работающего приложения(со старым или новым текстом, не важно)
3. Ветку с новым текстом в репозитории
